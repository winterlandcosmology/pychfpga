Introduction

pychfpga is a Python package that operates arrays of FPGA boards running the chFPGA firmware. It scales from a single benchtop board to hundreds of crate-mounted boards forming the digital front-end of a radio-telescope array.

pychfpga finds the boards, uploads the chFPGA bitstream that matches the requested operational mode, and initializes every firmware subsystem:

  • ADC data acquisition, including calibration

  • F-engine (channelizer): function generator, PFB/FFT, scaler and raw data capture

  • Corner-turn engine, within a board, a crate or between crates

  • Optional on-board X-engine (N² correlator) with (4 + 4j)-bit data

  • Optional 40G/100G Ethernet real-time offload to an external X-engine

Source code: https://github.com/winterlandcosmology/pychfpga

Features

  • Hardware map: tracks boards, crates and mezzanines, and how they connect.

  • Auto-discovery: boards are added by IP address, hostname, or board or crate serial number.

  • Concurrent operation: array operations run on all boards at once using asyncio. Used on arrays of 128 boards.

  • Array-wide synchronization: data acquisition is aligned across boards with GPS-derived timestamps or a distributed trigger.

  • Mode-based firmware selection: the bitstream matching the platform and mode is selected, uploaded and initialized automatically.

  • Servers: fpga_master and raw_acq run the array from a YAML configuration, accept REST commands, and publish Prometheus metrics.

Supported platforms and modes

The operational mode (the mode argument) selects the chFPGA firmware configuration that is loaded on the FPGA. Platform and configuration names follow chFPGA convention <platform>_<config>.
