eeprom_write(buf)

Writes a collection of bytes to the internal EEPROM.

Don’t do this unless you’re at McGill, and you’re commissioning and testing a new mezzanine! This method makes it trivial to delete non-volatile data. Figuring out how to re-write the original data is a tougher nut to crack.

According to FMC specs, the EEPROM is required to contain an IPMI FRU descriptor. If you want to insert this kind of data, you should use the ‘ipmi_fru’ module included in this Python repository.

Since EEPROM contents are parsed by machine and used during board bring-up, it’s important that the data you write is valid. You should refer to reference code (likely in the QC suite) rather than trying to guess what structures belong in here.

classmethod get_all_registered_classes(base_class_name=None)

Return a list of all currently-registered classes that have the same common hardware base class as cls or base_class_name (e.g. all Motherboard subclasses).

“Registered” means the class has already been imported and has declared itself via __init_subclass__. Classes listed only in the manifest are not included — use get_all_supported_classes() for that.

Used in discover_mezzanine, fpga_array

classmethod get_all_registered_instances(base_class_name=None)

Returns the live list of all instances of objects that have the same common Hardware base class as cls (e.g. all Motherboards instances). If base_class_name is not None, the instance list of the base class named base_class_name is returned instead.

The returned list is the actual internal registry, not a copy: it will reflect instances created or deleted after this call. This lets callers store e.g. self.motherboards = Motherboard.get_all_registered_instances() once and iterate the up-to-date set of motherboards without going through a property each time. As a consequence, callers must not mutate the returned list directly; use the HardwareMap API (instance creation, delete_instance, clear_hardware_map) instead.

Parameters:

base_class_name (str or None)

classmethod get_all_supported_classes(base_class_name=None, package=None)

Import every class declared in the manifest for the hardware base class of cls (or base_class_name) and return the resulting class list. Use this when a caller genuinely needs every possible class, not just the ones already loaded (e.g. EEPROM decoders that must try every mezzanine variant).

When package is given, the result is narrowed to classes declared in that subpackage under pychfpga.hardware (e.g. package='ice' to return only Ice-platform mezzanines). This is useful when a platform-specific routine must iterate over its own hardware variants, not every variant in the manifest.

classmethod get_class_by_ipmi_part_number(part_number, base_class_name=None)

Return the class whose official part number (cls.part_number) or aliases (cls._ipmi_part_numbers) matches the specified part_number.

Searches for the target part number in the _ipmi_part_numbers lists provided by each registered class. On miss, the manifest is consulted and the matching platform package is imported, then the lookup is retried — so callers never need to pre-load platforms.

There shall be only one class that matches the target IPMI. If there are multiple matches, a RuntimeError will be raised.

Parameters:

part_number (str) – target part number

Returns:

matching class, None if there are no matches. Raises a Runtime exception if there are multiple matches.

Used by discover_crate, discover_mezzanine, mdns_discover

classmethod get_class_by_part_number(part_number, base_class_name=None)

Return the hardware class whose part_number ends with part_number (case-insensitive).

Searches first the in-memory class registry for every hardware base class; if nothing matches, loads the full manifest (which may import previously-unseen platform packages) and retries. Used by the hardware map string parser to resolve user-supplied suffixes like MGK7MB or MGK7BP16.

Parameters:

  • part_number (str) – part-number suffix to match. Case-insensitive.

  • base_class_name (str) – if provided, restrict the search to the named hardware base class. Defaults to searching across every hardware base class (Motherboard, Crate, Mezzanine, …), because a part-number string like MGK7BP16 does not itself indicate which kind of hardware it describes.

Returns:

Matching class.

Raises:

RuntimeError – if zero or multiple classes match the suffix.
