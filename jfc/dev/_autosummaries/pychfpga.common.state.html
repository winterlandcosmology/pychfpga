class pychfpga.common.state.State(*args: Any, **kwargs: Any)

Bases: NameSpace

A dotted-access state tree with version-based change tracking.

Direct assignment (state.x = value) bumps a per-attribute version when the stored object identity changes. update(**kwargs) assigns flat values with equality checking. update_from(mapping) merges nested dict trees (e.g. JSON patches). In-place mutation is not tracked.

Each node also keeps a summary _gen incremented on every local version bump. has_changed() uses that integer for this node and walks nested State values (and State items in lists/tuples) so in-place child updates are visible. ack() snapshots the same tree for a consumer context; the two always match.

has_changed(attrs=None, *, context=None, ack=False)

Return whether this node or nested State children changed.

With attrs is None, this node’s summary _gen is tested, then nested children are walked. With explicit attrs, those slots’ versions are tested locally, then any State values among them are walked. ack() always snapshots the same tree.
