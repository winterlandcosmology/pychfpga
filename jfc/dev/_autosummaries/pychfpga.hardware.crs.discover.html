discover.py

List CRS boards on the network from UDP discovery beacons.

Sends a BEACONREQ broadcast, then listens for FWREQ/TCPIPE beacons. The default is a curses live table (autosized columns, last-seen times, rows greyed out after 10s). --dump collects beacons and prints a fitted table once.

python -m pychfpga.hardware.crs.discover python -m pychfpga.hardware.crs.discover –dump python -m pychfpga.hardware.crs.discover –dump -t 10

pychfpga.hardware.crs.discover.collect_beacons(timeout, port=9875, bind='0.0.0.0', on_new=None)

Listen for CRS discovery beacons and return one beacon per board serial.

on_new(beacon) is called the first time each board serial is seen. Later beacons for the same serial replace the stored entry but are not reported again.

pychfpga.hardware.crs.discover.constrain_widths(widths, term_width, gap=2)

Expand the last column to fill the terminal; never shrink other columns.

If the fitted row is wider than the terminal, the line is clipped on the right when it is drawn.

Return column widths that fit headers and every row.
