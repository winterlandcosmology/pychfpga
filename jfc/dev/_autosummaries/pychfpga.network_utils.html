network_utils.py

Network utilities for verifying system settings required for UDP data reception.

This module provides functions to check if the system is properly configured for receiving high-rate UDP data streams without packet loss.

Module functions summary

check_interface_mtu

Check if the specified interface has jumbo frames enabled (MTU >= 9000).

check_udp_buffer_settings

Check UDP buffer memory settings.

find_best_interface

Find the best network interface for hardware communication.

get_interface_for_ip

Determine which network interface can reach the target IP.

get_network_interfaces

Get list of available network interfaces.

show_network_status

Print current network configuration status.

verify_network_settings

Verify all network settings required for UDP data reception.

Module functions

pychfpga.network_utils.check_interface_mtu(interface: str) → Tuple[bool, int]

Check if the specified interface has jumbo frames enabled (MTU >= 9000).

Parameters:

interface – Network interface name (e.g., ‘eno1’)

Returns:

Tuple of (is_jumbo_enabled, current_mtu)

pychfpga.network_utils.check_udp_buffer_settings() → Dict[str, Tuple[bool, int, int]]

Check UDP buffer memory settings.

Returns:

Dictionary with keys – ‘rmem_max’, ‘rmem_default’, ‘udp_mem’, ‘udp_rmem_min’ Values are tuples of (is_sufficient, current_value, required_value)

pychfpga.network_utils.find_best_interface(serial_number: str = None) → str | None

Find the best network interface for hardware communication. If serial_number is provided, discovers the CRS board and finds the interface that can reach it. Otherwise, prioritizes interfaces with jumbo frames already enabled.

Parameters:

serial_number – Serial number of CRS board to discover (e.g., ‘0016’)

Returns:

Interface name or None if no suitable interface found

pychfpga.network_utils.get_interface_for_ip(target_ip: str) → str | None

Determine which network interface can reach the target IP. Uses ‘ip route get’ command to find the appropriate interface.

Parameters:

target_ip – Target IP address to check routing for

Returns:

Interface name that can reach the IP, or None if not found

pychfpga.network_utils.get_network_interfaces() → List[str]

Get list of available network interfaces.

Returns:

List of interface names

pychfpga.network_utils.show_network_status(interface: str = None) → None

Print current network configuration status.

Parameters:

interface – Specific interface to check. If None, checks all.

pychfpga.network_utils.verify_network_settings(interface: str = None) → Tuple[bool, List[str], List[str]]

Verify all network settings required for UDP data reception.

Parameters:

interface – Specific interface to check. If None, finds best available.

Returns:

Tuple of (all_ok, error_messages, fix_commands)
