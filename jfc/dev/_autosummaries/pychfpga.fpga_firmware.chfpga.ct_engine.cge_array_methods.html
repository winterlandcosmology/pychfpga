cge_array_methods.py

Array-wide signal-integrity methods for the CGE (100G) link and its QSFP28 optical module.

Registered by CGE, so on a CRS array:

ca.set_fpga_tx(*ca.nearest_tx_codes(950, 0.01, 0))   # FPGA TX swing / pre-cursor / post-cursor
ca.read_optical()                                     # optical module SI settings and latched flags
ca.set_optical(adaptive=False, tx_eq=5)               # manual optical module settings (volatile)
ca.retrain_optical()                                  # module TX input equalizer adapts again
ca.restore_si_defaults()

Every method takes serials= (e.g. ['0224']) to act on some boards only. FPGA TX drive and RX LPM need a bitstream with the CGE TX drive control bytes; on older firmware the CGE methods refuse to write.

restore_si_defaults(tx=(24, 0, 15), serials=None)

FPGA TX codes tx (default 24/0/15 = 950 mV, 0.01 dB, 3.99 dB: the chfpgalite reset value from 07c6572 on; older bitstreams reset to 24/0/0 or 0/0/0), FPGA RX DFE, optical module reset.

retrain_optical(method='toggle', wait=1.0, serials=None)

Make the optical module TX input equalizer adapt again to the current FPGA signal.

‘toggle’: adaptive enables off, then back (other settings kept; boards without adaptive EQ on are skipped). ‘reset’: pulse ResetL (ALL module settings back to power-on values; the link drops briefly; waits >= 2 s). Prints the latched flags after the wait: TX CDR LOL set means the module input was acquired again.

set_fpga_rx_lpm(enable, serials=None)

FPGA receiver equalizer on all 4 lanes: LPM (True) or DFE (False). Affects only what the CRS receives.

set_fpga_tx(swing=0, pre=0, post=0, lanes=range(0, 4), serials=None)

Set FPGA TX swing / pre-cursor / post-cursor codes (0-31) on lanes of each board. Returns the read-back.

set_optical(tx_eq=None, rx_emph=None, rx_amp=None, adaptive=None, serials=None)

Set optical module SI settings; None leaves a setting unchanged. One value for all channels or a list for channels 1-4: tx_eq / rx_emph in dB, rx_amp as a code, adaptive True/False. Volatile. Returns read_optical().
