qsfp_ber_tests.py

QSFP (CGE 100G) loopback BER tests: every board tests its own QSFP lanes at the same time.

Each board sends PRBS-31 on QSFP TX lane n and checks it on its own RX lane n through a loopback plug (passive copper, or an optical module with a loopback fibre). Needs the crs_ct bitstream (FPGAArray mode=’shuffle8’) with the CGE TX drive control bytes.

Results are keyed by (slot, lane). Long functions take optional callbacks: log(str), progress(done, total), partial(obj) for live display, and stop() -> bool to abort.

Module functions

pychfpga.apps.ber_dashboard.qsfp_ber_tests.best_index(zero, ber)

Index of the best grid point. Among 0-error points: the one farthest (in grid steps, same swing) from any point with errors; ties go to the point nearest the centre of the pre/post grid. Without any 0-error point: the lowest BER.

pychfpga.apps.ber_dashboard.qsfp_ber_tests.check_loopback(boards, swing=0, pre=0, post=21, lpm=False, log=<function _noop>)

Check that TX lane n reaches RX lane n of the same board. The pattern of one TX lane at a time is stopped (on every board at once); an RX lane is hit if its BER during the stop is above 0.1 (a stopped pattern gives about 0.5). Lanes without lock or with a BER above 0.05 at this setting are reported, not judged. Returns {(slot, lane): dict(rx_lanes_hit, background_ber, ok)}.

pychfpga.apps.ber_dashboard.qsfp_ber_tests.lpm_by_plug(plugs)

‘Auto’ receiver mode: LPM behind an optical module, DFE behind a copper plug (measured on CRS rev5: passive copper loopbacks fail in LPM, optical SR4 modules are best in LPM). {slot: bool}.

pychfpga.apps.ber_dashboard.qsfp_ber_tests.measure(boards, dwell=1.0, train=2.0, lock_proof=True)

Retrain the RX equalizers, wait train s, clear the counters, count PRBS-31 errors for dwell s. Lock proof: stop the transmitted pattern for 0.3 s; a locked checker must count errors. Returns {(slot, lane): dict(errors, ber, locked)}; ber of 0 errors is the 1/bits floor.

pychfpga.apps.ber_dashboard.qsfp_ber_tests.qsfp_boards(ca)

Boards with a CGE that has the TX drive control bytes, sorted by slot.

pychfpga.apps.ber_dashboard.qsfp_ber_tests.read_plugs(ca, log=<function _noop>)

Identify what is in each QSFP cage: {slot: dict(serial, vendor, part, kind, si…)}. Never raises.

pychfpga.apps.ber_dashboard.qsfp_ber_tests.rearm(boards)

Reset the PRBS error counters. A checker that lost the pattern (lock proof, stopped lane) only locks again after this reset.

pychfpga.apps.ber_dashboard.qsfp_ber_tests.scan_eyes(boards, h=range(-32, 33, 4), v=range(-50, 51, 5), max_prescale=5, log=<function _noop>, progress=<function _noop>, stop=<function _noop>)

Eye diagram of every lane at the present TX / RX settings (DFE or LPM from RXLPMEN). Returns {(slot, lane): ber_map[len(h), len(v)]}.

pychfpga.apps.ber_dashboard.qsfp_ber_tests.set_prbs(boards, tx=5)

PRBS-31 checker on all lanes; PRBS-31 (tx=5) or no pattern (tx=0) from all transmitters. Control byte 7 is copied to the selected lane, so every lane gets the same value.

pychfpga.apps.ber_dashboard.qsfp_ber_tests.set_rx_lpm(boards, lpm)

lpm: True (LPM), False (DFE), or {slot: bool} per board.

pychfpga.apps.ber_dashboard.qsfp_ber_tests.sweep_tx(boards, swings, pres, posts, dwell=1.0, lpm=True, train=2.0, log=<function _noop>, progress=<function _noop>, partial=<function _noop>, stop=<function _noop>)

FPGA TX grid on every board at once. Returns dict(swings, pres, posts, lpm, dwell, ber={(slot, lane): array[len(swings), len(pres), len(posts)]}, zero=…, locked=…, temps=[…]). partial(result) is called after each TX pre-cursor row.
