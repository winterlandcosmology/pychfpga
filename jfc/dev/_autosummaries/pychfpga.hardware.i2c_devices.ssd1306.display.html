print(text, x=None, y=None, fg=None, bg=None, update=True, font_name=None, font_size=None, rotate=False)

Print text in the frame buffer

Parameters:

  • text (str) – string to print

  • x (int) – coordinate of where to start to print. If not specified, continues from last current location.

  • y (int) – coordinate of where to start to print. If not specified, continues from last current location.

  • fg (int) – sets the foreground and background color by calling set_fg_color() and set_bg_color . If not specified, the current colors are used.

  • bg (int) – sets the foreground and background color by calling set_fg_color() and set_bg_color . If not specified, the current colors are used.

  • update (bool) – if True, the the frame buffer is sent to the display after the print is complete.

  • font_size (int) – Indicates which font to use by calling set_font(). If not specified, the current font is used.
