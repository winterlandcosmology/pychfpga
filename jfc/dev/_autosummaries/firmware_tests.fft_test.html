pack_funcgen_adc_lanes(adc_lanes)

Pack parallel ADC lane streams into the FUNCGEN RAM layout.

The arbitrary FUNCGEN API accepts a single one-dimensional buffer, but that buffer is not conceptually a serial scalar waveform when it feeds the channelizer. It is the RAM image consumed by the firmware’s parallel ADC/F-engine input interface. One channelizer clock contains SAMPLES_PER_WORD ADC samples, and the host buffer must therefore be interleaved by lane:

buffer[0::N] -> ADC/F-engine input lane 0 buffer[1::N] -> ADC/F-engine input lane 1 … buffer[N-1::N] -> ADC/F-engine input lane N-1

This is the same convention shown in fft_sim_test_example.py for replaying CASPER simulation inputs: take 512 samples from each of the four parallel ADC input signals and interleave them into one 2048-sample FUNCGEN buffer. Keeping that packing in a named helper is deliberate: FFT tests should construct the signal at the parallel input boundary and let this function create the write image. Writing a generated NumPy waveform directly to set_funcgen(data=...) hides that boundary and makes it easy to accidentally compare a scalar serial ordering against a four-lane firmware datapath.

The helper only performs input packing. It does not rename or fold FFT output bins, and it does not compensate a failing result by changing the NumPy reference. If a tone still lands in a different captured bin after this packing, the mismatch is exposed in the test output and should be investigated as an FFT/capture convention issue rather than concealed in the reference spectrum.

pack_scalar_waveform_for_funcgen(waveform)

Convert a scalar time-series frame into FUNCGEN lane-interleaved RAM.

Tests often start from a convenient scalar sequence because NumPy FFT references are naturally written that way. Before programming FUNCGEN, split that scalar sequence at the parallel ADC boundary and call pack_funcgen_adc_lanes. For a correctly ordered scalar waveform this gives lane 0 samples 0, N, 2N, ..., lane 1 samples 1, N+1, ..., and so on, then writes the explicit lane-interleaved RAM image.
