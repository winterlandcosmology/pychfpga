cge.py

cge.py module

Implements interface to the 100G Ethernet FPGA module

Per-lane GT transceiver lab access (BER, eye scan) is via CGE.gtx[i] (CGEChannel). CMAC core DRP is via CGE.core (CGECore); GT common (QPLL) DRP via CGE.gt_common (CGECommon). PRBS pattern select and checker reset use minimal CMAC GT fabric ports on CGE (not available via DRP).

Module classes summary

CGE

Interface to the 100G Ethernet FPGA module (CMAC, GT lanes, and DRP).

CGEChannel

Per-lane GTY channel DRP on a CGE block (UG578 GTYE3_CHANNEL).

CGECommon

GT common (QPLL) DRP on a CGE block.

CGECore

CMAC core DRP (PG203).

enable_eye_scan(lanes=range(0, 4))

Set the eye-scan masks (UG578: 160-bit, all 80 current bits counted) and ES_EYE_SCAN_EN on lanes, reset the RX datapath (needed for ES_EYE_SCAN_EN), then calibrate each lane’s phase. The RX reset restarts the PRBS checkers: reset the error counters afterwards.

set_rx_lpm(enable, lanes=range(0, 4))

Select the RX equalizer of lanes: LPM if enable, else DFE. Pulses RXDFELPMRESET on each lane. RXDFELPMRESET is in control byte 7, which is copied to the selected lane: keep byte 7 the same on all lanes.

set_tx_drive(lane, swing=0, pre=0, post=0)

Set GT lane TX swing (TXDIFFCTRL), pre-cursor (TXPRECURSOR) and post-cursor (TXPOSTCURSOR) codes, 0-31 each. 0/0/0 = 390 mV, 0.01 dB, 0 dB. Firmware reset value: 24/8/15 = 950 mV, 1.87 dB, 3.99 dB. Values: TXDIFF_MV, TXPRE_DB, TXPOST_DB.

tx_drive_supported()

True if the firmware has the TX drive and RXLPMEN control bytes (chfpgalite jm/cge-tx-drive-ctrl). Read-only: on older firmware byte 9 aliases byte 1 (TEST_PACKET_WORDS), so the two read the same.

write(addr, data, *args, **kwargs)

Writes an array of bytes to the FPGA memory-mapped address space. Address addr is relative to the base address of the current MMI module.

The MSBs of addr determines the page in which data is written (control, status, RAM etc.). use write_control(...), write_ram(...) etc. to write to specific pages.

Returns the number of bytes written.

write_DRP(addr, data)

Writes a 16-bit value data to a register of a DRP (Dynamic Reconfigurable Port) of the FPGA internal devices (PLL, SYSMON, MGT etc).

Parameters:

  • addr (int) – Address of the 16-bit DRP register word (the address is internally multiplied by 2 to convert it to a byte address)

  • data (int) – 16-bit value to be written

Notes

  • The DRP and RAM pages use the same address space. Either one or the other is connected to the module.

  • The DRP values are stored as little endians

class pychfpga.fpga_firmware.chfpga.ct_engine.cge.CGEChannel(cge, port, lane)

Bases: _CGEDrpPort

Per-lane GTY channel DRP on a CGE block (UG578 GTYE3_CHANNEL).

Same high-level API as xxvglink.GTY for get_ber, get_eye_diagram, and plot_eye_diagram. Those methods call select() once; other DRP access requires the caller to select first. PRBS fabric is on CGE (bytes 7-8); use select_gt_lane then set RXPRBSSEL etc. on the parent block.

One eye-scan accumulation at horizontal offset h (-32..32 = -0.5..0.5 UI) and vertical offset v (-127..127 counts). The prescale rises until min_errors or max_prescale. Returns (errors, bits). Port must be selected; eye scan must be enabled (CGE.enable_eye_scan()).

get_eye_diagram(horiz_offset=[-32, -28, -24, -20, -16, -12, -8, -4, 0, 4, 8, 12, 16, 20, 24, 28, 32], vert_offset=[-50, -45, -40, -35, -30, -25, -20, -15, -10, -5, 0, 5, 10, 15, 20, 25, 30, 35, 40, 45, 50], max_prescale=5, min_errors=100, lpm=None)

Return the BER at every (horizontal, vertical) offset as an EyeDiag; ber_map has shape (len(horiz), len(vert)). A point with no errors reads as the BER floor of that point.

horiz_offset: -32 to 32 (-0.5 to 0.5 UI). vert_offset: -127 to 127 counts (2.4 mV per count at the default range). lpm: receiver equalizer mode; None reads it from the parent CGE (RXLPMEN), DFE on firmware without it. Eye scan must be enabled first (CGE.enable_eye_scan()). The lane is re-calibrated here.
