class pychfpga.common.perf.Perf

Bases: object

Named wall-clock phases, optionally nested.

start(name) records a start time. By default it also stops the currently running sequential phase so successive start() calls form a chain of siblings at the same hierarchy level. Use stop_current=False to time an overlapping phase.

start(name, subtask=True) pushes a child of the current phase. The parent keeps running. If there is no current phase, the first subtask starts as a top-level phase (same as subtask=False). stop() pops one level. Until stop(), further start(..., subtask=True) calls stay under the current subtask.

times maps path_tuple -> (start_time, stop_time, duration). stop_time and duration are None while the phase is running. Times are time.perf_counter() values. The display name is the last component of the path.

__init__()
get_delay(from_=None, to=None)

Elapsed seconds from one phase to another.

Measured from the start of from_ to the stop of to (or now if to is still running). from_=None is the first recorded phase; to=None is the last.

from is a Python reserved word, so the argument is from_. A string matches (name,) or a unique leaf name.

Examples:

perf.get_delay()
perf.get_delay('ping', 'open platform')
perf.get_delay(from_='hardware map')
perf.get_delay(to='mezzanines')
start(name, stop_current=True, description=None, subtask=False)

Start phase name.

Parameters:

  • name (str) – Phase name (last path component). Re-starting a finished path overwrites it.

  • stop_current (bool) – If True (default) and subtask is False, stop the current leaf and start name as a sibling (same parent). If False, start an overlapping timer without changing the current sequential phase.

  • description (str) – Optional text shown in summary().

  • subtask (bool) – If True, push name under the current phase. Does not stop the parent. With no current phase, starts name at the top level instead.

stop(name=None)

Stop phase name (or the current leaf if omitted).

With no argument, pops one hierarchy level. Returns the duration in seconds.

summary(stop_running=True)

Return a text table of phase start, stop, and duration.

Times are seconds relative to the first start(). If stop_running is True (default), still-running phases are stopped innermost-first so leftover subtasks do not leave parents running.

A total row is the wall time from the earliest start to the latest stop. Nested phase names are indented by depth.
