Object representing a HDF5 file containing N-squared correlation data.

UCORR integrations arrive pre-formatted as (NBINS, NPROD) arrays (capture_engine='UCORR'). Legacy ICE correlators use raw (CORR, CMAC, PROD) arrays remapped through CORR.get_raw_corr_map().
