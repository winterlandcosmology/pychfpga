UDPPacketReceiver

Receives and stores UDP packets until the buffer is full or a timeout has occurred.

Module classes

class pychfpga.common.udp_packet_receiver.UDPPacketReceiver(sock, buf_size=8192, max_packet_size=9000, verbose=1, report_pkt_len_me: int = 0, threaded: bool = True)

Bases: object

Receives and stores UDP packets until the buffer is full or a timeout has occurred.

Parameters:

Parameters:

  • sock (socket.socket) – Socket used for receiving UDP packets.

  • buf_size (int) – Packets per batch (public buf and each ping-pong fill buffer). Default 8192 is large enough that, with two buffers, one can fill through a format stall (~160 ms at ~70 kpkt/s) while the other sits ready.

  • max_packet_size (int) – Maximum expected UDP payload length (second axis of buf).

  • threaded (bool) – If True (default), a background thread drains the socket into two ping-pong fill buffers while the consumer processes the previous batch. After receive_packets() returns, buf, pkt_len and n_stored hold the current batch; buf keeps the same array identity (the completed batch is copied into it) so cached views stay valid. Set False for the legacy inline behavior.

close()

Stop the background receiver thread (threaded mode). Safe to call repeatedly.

flush(timeout=0.001, max_flush_time=2, verbose=0)

Flush the UDP buffer (read packets until timeout). Note: Partial frame data may start to fill the UDP buffer while we start to flush it. There is still likely a partial frame in the buffer after this operation.

gettimeout()

Returns the current timeout on the socket

Returns:

float – current timeout in seconds

receive_packets(verbose=None)

Receive packets until timeout or the buffer is full.

In threaded mode this hands back the next ping-pong batch (copying it into buf so its identity is stable), blocking up to the consumer timeout for one to appear. In inline mode it drains the socket directly (legacy behavior).

Parameters:

verbose (int or None) – If None, use verbose on this receiver. If set, that level is used for this call only (it is not raised to match verbose), so a parent such as RawFrameReceiver can force quiet UDP logs with verbose=0 even when the packet receiver was constructed with a higher default.

udp_socket_stats()

Return (rx_queue_bytes, drops) for this UDP socket, or None.

Reads /proc/net/udp (Linux). drops is the kernel’s per-socket RCVBUF overflow counter — the same column watch cat /proc/net/udp shows.
