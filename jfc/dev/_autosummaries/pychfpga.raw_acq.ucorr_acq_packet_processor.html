filter_packets(n: int) → ndarray | None

Decode UCORR headers; leave integration index in pkt_ts; return frame indices.

Each of the n received datagrams packs up to FRAMES_PER_PACKET aggregated records (firmware TLAST gating). We decode over the flat (n, nf) record grid and return a 1D linear frame index bix into the M = n_packets * nf scratch space, so the base-class pipeline (pkt_ts[bix], bix_mask[bix], unique-timestamp merge) is reused as-is.

get_formatted_data(rows=slice(None, None, None), **kwargs)

Return formatted integration rows assembled by the last process_udp_packets call.

Remaps accumulator rows into (NBINS, NPROD) complex outputs. acc_re/acc_im/sat are indexed by (integ, NDECIM, NCORRS, NPROD_PER_CMAC, NCMAC); bin_map (4D) and prod_map (3D) broadcast together to place each product into the dense (NBINS, NPROD) plane. The scatter uses a single precomputed flat index (see _ensure_flat_scatter_idx()): we build a compact (nrows, K) complex source from the real/imag accumulators, then scatter it once per output array. The output rows are cleared first so cells the maps do not cover stay zero rather than leftover data from the previous integration.

Parameters:

rows (slice or int) – Physical index rows in the internal assembly buffer. None or slice(None) selects out_rows. An int selects slice(0, rows), then clipped to out_rows.

Returns:

None if no rows are ready; otherwise (integ_ts, data, counts, sats) where integ_ts and counts have shape (n,), and data and sats have shape (n, NBINS, NPROD).

Raises:

TypeError – If source or format keyword arguments are passed.

get_good_bin_mask()

Return a boolean map of FFT bins expected to contain valid correlator data.

True for bins present in bin_map, except correlator sacrificial readout bins (stolen for the accumulation-memory readout cycle). Culled bins (e.g. the first 256 FFT bins dropped at CT level 2) stay False because they are absent from bin_map.

READOUT_BIN is a compile-time generic and does not follow FFT bypass. config.READOUT_BINS is one clkbin per correlator (from chFPGA.CORR_READOUT_BINS).

The mask length is NBINS (typically 8192). Reads bin_map, NBINS, and READOUT_BINS from the correlator config. Does not call update_config().

get_ij_to_prod_map()

Return the (i, j) → linear product-index map for the current NCHAN.

Reads NCHAN from the correlator config returned by config_getter. Does not call update_config() (no packet-buffer reallocation).

process_udp_packets(verbose=None, update_config=True)

Assemble one active UDP packet block into internal raw buffers.

Filters packets, merges timestamps with carryover, scatters payload bytes, and publishes ready rows as out_rows (physical slice) and n_out (visible count). Index via out_rows; n_out is only a count.

Future: get_formatted_data returns row indices into the raw buffer, so a follow-up can replace compaction/carry-over with a ring-buffer layout.

Parameters:

verbose – Verbosity level, or None to use self.verbose.

Returns:

None. Ready rows are stored in self.out_rows; self.n_out is out_rows.stop - out_rows.start.
