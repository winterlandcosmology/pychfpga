i2c_devices/

I2C peripheral helper classes and drivers.

Package sub-modules

TICSPRO_loader

Helpers for parsing TICSPRO-generated register configuration files.

amc6821

amc6821.py module: Provides a class to read/write to the AMC6821 fan controller chip

eeprom

EEPROM.py module Implements an object to interface through a I2C EEPROM

gpio

Generic GPIO accessor on top of I2C expander backends.

hmc7044

hmc7044: Interface to the Analog Device HMC7044 PLL.

ina230

ina230: Implememnts access to a INA230 I2C current/power monitor.

lmk04208spi

Interface to the LMK04208 PLL via the SC18IS202 II2-to-SPI bridge.

lmx2594spi

lmk04208spi: Interface to the LMK04208 PLL via the SC18IS202 II2-to-SPI bridge.

pca6524

Implememnts interface to the pca6524 I2C IO expander with 3 8-bit ports.

pca8574

Implememnts interface to the PCA8574 I2C 8-bit IO expander.

pca9546a

pca9546a.py module Defines a class that implements the interface to the PCA9546A 4-port I2C switch.

pca9575

pca9575: Implememnts access to a TCA9548A I2C switch.

pca9698

Interface for the PCA9698 I2C switch.

qsfp

qsfp.py module: Provides a class to read/write to a QSFP cable

sc18is602b

sc18is602b: Interface to the SC18IS602B II2-to-SPI bridge.

ssd1306

SSD1306 OLED display helpers and drivers.

tca6416a

Implememnts interface to the TCA6416A I2C IO expander.

tca9544a

tca9544a.py module Defines a class that implements the interface to the TCA9544A I2C switch.

tca9548a

tca9548a.py module Defines a class that implements the interface to the TCA9548A I2C switch.

tmp100

Implements the interface for the TEMP100 I2C temperature sensor.

tmp421

Implememnts the interface to a TEMP100 I2C temperature sensor.
