Format one S3 record line (data is a uint8 numpy array, len <= RECORD_LEN).

send(filename, line_batch=1, drain_timeout=0, timeout=300)

Send a file as S-records for U-Boot loads (no per-line ACK).

Each S-record line is sent in its own datagram so U-Boot’s 512-byte netconsole input buffer is not overrun mid-line. drain_timeout should stay at zero; a non-zero value adds per-line latency on high-RTT links.
