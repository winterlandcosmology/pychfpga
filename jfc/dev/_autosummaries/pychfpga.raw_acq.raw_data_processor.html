create_output_buffer(n_ts, source=0, split=False, format=None, complex_override=None)

Create arrays to store the timestamps, formatted data, and data counts returned by process_packets.

This is used by applications that need to crate a storage space for the formatted data returned by the process_packets method. Arrays are allocated with numpy.empty; callers that rely on defined values for unfilled rows (e.g. partial read_raw_frames) should zero them before use.

Parameters:

  • n_ts (int) – Number of timestamps to create the output buffer for.

  • source (int) – The source index

  • split (bool) – If True, split each burst into frames_per_burst rows with consecutive timestamps and per-frame packet counts

Returns:

Tuple of ts (n_ts,), data, and counts (n_ts, nchan).

process_udp_packets(verbose=None)

Assemble one active UDP packet block into internal raw buffers.

Filters packets, merges timestamps with carryover, scatters payload bytes, and publishes ready rows as out_rows (physical slice) and n_out (visible count). Index via out_rows; n_out is only a count.

Future: get_formatted_data returns row indices into the raw buffer, so a follow-up can replace compaction/carry-over with a ring-buffer layout.

Parameters:

verbose – Verbosity level, or None to use self.verbose.

Returns:

None. Ready rows are stored in self.out_rows; self.n_out is out_rows.stop - out_rows.start.
