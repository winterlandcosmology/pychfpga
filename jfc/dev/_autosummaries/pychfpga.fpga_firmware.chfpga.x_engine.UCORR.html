update_config()

Refresh correlator maps if needed and return self.config.

Build bin_map / prod_map onto config from primary parameters.

Maps produced here (and exposed via update_config()) are authoritative for packet processing; receivers should transmit bin_map / prod_map rather than recomputing them.

Identical (CT_LEVEL, NDECIM, NCHAN, NCLK, fft_bin_map) inputs share one class-level cache entry so every board in an array reuses the same arrays instead of rebuilding a ~13 M-element map.

If the following primary parameters are changed: - CT_LEVEL: CT level - NDECIM: number of decimation bins - NCHAN: number of channels - NCLK: number of clocks - fft_bin_map: FFT bin map - autocorr_only: when set, the last map axis is the diagonal CMACs only

The following parameters are then updated: - bin_map: (bin_set, corr, clkbin, prod) = bin - prod_map: (corr, clkbin, prod) = pix - conj_map: (corr, clkbin, prod) = True where the firmware product is conj(V_ij) - NDECIM: number of decimation bins - NCORRS: number of correlators - NPROD_PER_CMAC: number of products per CMAC - NCMAC: number of CMACs - NBINS: number of bins - NPROD_PER_ARRAY: number of products per array

write(addr, data, *args, **kwargs)

Writes an array of bytes to the FPGA memory-mapped address space. Address addr is relative to the base address of the current MMI module.

The MSBs of addr determines the page in which data is written (control, status, RAM etc.). use write_control(...), write_ram(...) etc. to write to specific pages.

Returns the number of bytes written.

write_DRP(addr, data)

Writes a 16-bit value data to a register of a DRP (Dynamic Reconfigurable Port) of the FPGA internal devices (PLL, SYSMON, MGT etc).

Parameters:

  • addr (int) – Address of the 16-bit DRP register word (the address is internally multiplied by 2 to convert it to a byte address)

  • data (int) – 16-bit value to be written

Notes

  • The DRP and RAM pages use the same address space. Either one or the other is connected to the module.

  • The DRP values are stored as little endians
