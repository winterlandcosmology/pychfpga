Ccoll: Concurrent (or Callable) collection: list-like or dict-like container that allows attribute accesses and method calls to be performed on concurrently on all its items.

__call__(*args, **kwargs)

Call every object in the collection with the same arguments.

For ordinary callables, returns a Ccoll of return values. For coroutine functions, returns an awaitable that gathers them and resolves to a Ccoll of results, e.g.:

results = await self.ib.foo_async(x)
