TCP framed packet receiver compatible with UDPPacketReceiver.

Bases: object

Receives framed TCP streams into the same buffer contract as UDPPacketReceiver.

Each record is cookie(u16 LE)=0xDA4A, counter, counter ^ 0xFFFF, length, then length payload bytes. Accepts a list of connected TCP sockets (typically one per board).

Multi-socket receive is fair: sockets are drained round-robin so one busy board cannot fill the packet buffer alone (which would leave other channels as zeros after assembly).

The data sockets are assumed stable for a session (firmware drops on backpressure instead of closing). Reconnect by calling get_data_receiver_async(..., force=True) on array reinit.

flush(timeout=0.001, max_flush_time=2, verbose=0)

Discard complete framed records until the stream goes quiet.

Bytes are fed through the per-socket carry buffer so a trailing partial record is preserved (unlike clearing carry, which desyncs the stream). Stops when no socket is readable for timeout (typically less than the inter-timestamp gap). max_flush_time is only a hang safety if the stream never quiets.
