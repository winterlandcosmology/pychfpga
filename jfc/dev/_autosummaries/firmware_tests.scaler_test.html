test_all_zeroes(setup_scaler, xr)

Verify that zero digital gain forces scaler output to zero for the full input range.

The test programs the channelizer to capture scaler output (capture mode 0), feeds a full-range ramp into FUNCGEN in FFT-bypass mode, and checks that the received scaler stream is exactly zero on every sample.

test_alternating_gain(period, setup_scaler, xr)

Verify per-bin gain alignment using a periodic sparse gain mask.

The gain table is set to zeros except every period-th bin, which is set to 1. The input is a periodic ramp to avoid long flat segments, so misalignment between gain-bin indexing and input-bin ordering is visible in the captured output.

Parameters:

period (int) – period in number of bins of the pattern

test_counter_reset(setup_scaler, xr)

Tests the reset signal by ensure that various counters are always 0 as long as the reset signal is high, and that they are (mostly) non-zero when it is low.

Notes

Runs scaler capture mode 0, holds SCALER reset high to validate zeroed monitor counters, then releases reset and verifies counters become active.

test_delay_counter(setup_scaler, xr)

Tests that all channelisers all start recieving data at the same by ensuring that the delay counters, which measure clocks from sync until first data is recieved, are equal.

Notes

Resets scaler pipelines, performs one scaler capture using the current raw-frame API, then checks DELAY_CTR uniformity across channels.

test_gain_bank_switching(setup_scaler, xr)

Test that gain-bank switching takes effect and that the gain bank status variable reflects the switch.

Notes

Uses a runtime flow for robustness with the current receiver API: capture a frame, switch bank immediately, wait 1 second, capture another frame, and compare against before/after references.

test_offset_encoding(postscaler, setup_scaler, xr)

Similar to the all_ones test, but ensures that binary offset encoding is correctly applied to the output.

Parameters:

postscaler (int) – postscaler(s) to employ with this test

Notes

Uses scaler capture mode 0. The packet processor already converts offset-binary samples to signed, so the reference is the signed clipped scaler output.

test_ramp_gains(setup_scaler, xr)

Sets the gains to a periodic ramp betwen gain_min and gain_max and ensures that they are correctly applied to the input bins

Notes

Uses _set_capture_scaler with the current raw-frame capture API and the currently configured scaler capture mode.
