Take Primative Data from IceBoard

This tutorial assumes that you have run the fpga_array.py script and have a FPGAarray object in Python named ca.

Ramp ADC Data

For this step, the IceBoard must have been initialized without mezzanines.

Say you want to take data from a board x in your hardware map. Begin by selecting that board:

b = ca.ib[x]

Next, set the data capture mode to ADCs:

b.start_data_capture(source='adc',period=1)

Now we define a data receiver:

r = b.get_data_receiver()

And we can now capture data from the ramp into a variable called data:

data = r.read_frames()
