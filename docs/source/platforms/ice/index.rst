--------
IceBoard
--------

The IceBoard (MGK7MB) is a Kintex-7 FPGA board with an ARM processor running Linux, designed by
McGill University for large synchronized arrays. It takes one or two MGADC08 8-channel ADC
mezzanines and is used standalone or in MGK7BP16 (16-slot) and MGK7BP1 (1-slot) crates.

Hardware documentation: https://icecore-docs.readthedocs.io
